В схеме аттестации 70% и 50% — прозрачные пилотные правила, а не психометрически откалиброванные границы квалификации. Рейтинг подбора показывает вклад сведений и ограничений, а не вероятность найма. Контактное разрешение и передача выбранных полей в ATS — отдельные действия кандидата.

Архитектура показывает worker как поток в приложении, PostgreSQL как постоянное хранилище и ограниченную SQL-проверку в отдельном процессе с SQLite только в памяти. Подключаемые ФСП/ATS-контракты не обозначают действующее подключение официальных партнёрских систем; основной стенд не использует ML и нейрогенератор. ATS ACK сохраняет ответ получателя об удалении, а не доказывает очистку всех его систем.
