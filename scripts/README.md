# Скрипты проекта

Начните с [установки](../docs/INSTALLATION.md) и [результатов проверок](../docs/VERIFICATION.md). Скрипты ниже обслуживают воспроизводимую поставку и изолированные проверки; они не содержат доступов к действующему серверу.

| Задача | Скрипт |
|---|---|
| Создать первого администратора своей установки | `create_admin.py` |
| Проверить email, навигацию и OIDC в настоящем браузере | `check_delivery.py`, `browser_final_release.py` |
| Изолировать тесты PostgreSQL | `postgres_test_context.py`; pytest с `FSP_TEST_POSTGRES_DSN` |
| Полный синтетический путь аттестации | `measure_full_assessment.py` |
| Чувствительность правил и длины формы | `measure_assessment_policy.py`, `measure_assessment_forms.py` |
| Предметный каталог и варианты | `validate_assessment_v2.py`, `measure_form_content.py` |
| Перенос рабочего решения и отрицательные ответы | `measure_work_transfers.py` |
| Подбор с разделением семейств настройки/оценки | `measure_ranking_v3.py` |
| Актуальность подтверждений через реальный API | `measure_matching_lifecycle.py` |
| Первый проход текущих двух ролей | `browser_final_journey.py`, `browser_balanced.py` |
| Внешний ATS-клиент и полный цикл | `ats_bridge.py`, `ats_reference_cycle.py` |
| Reference-провайдер уведомлений, OIDC и генератора | `reference_integrations.py` |
| Изолированный ФСП ID-мок | `mock_fsp_id.py` |
| Импорт публичного источника вакансий | `import_work_russia.py` |
| Резервная копия своей PostgreSQL и проверка восстановления | `backup_database.py`, `rehearse_postgres_recovery.py` |
| Упаковка разрешённого комплекта сдачи | `package_submission.py` |

Параметры отдельного скрипта смотрите через `--help`, если он предоставляет CLI. Браузерные проверки используют Playwright и Chromium; установка браузера — `python -m playwright install chromium`. Контрольные сценарии создают синтетические аккаунты, запросы, приглашения и временные схемы. Запускайте их на **отдельном проверочном контуре**, а не на рабочем PostgreSQL с историей пользователей.

Скрипты с `stage03/stage04`, `demo` или историческим названием сохраняют проверки прежних совместимых путей. Их условия не являются инструкцией входа в действующий публичный сервис; часть UI-сценариев требует соответствующей исторической формы и отдельного DEMO/TEST_LOGIN-стенда. Общих публичных деморолей в поставке нет.

Необязательные загрузчики моделей и генератор не нужны для основного подбора или аттестации v3. Базовый путь работает при `FSP_ENABLE_ML=0`; действующая v3 собирает собственные проверяемые формы без нейрогенерации.

Результаты новых запусков сохраняются локально; рабочие DSN, ключи, пароли и сообщения пользователей не публикуются. Поставляемые отчёты — фиксированные технические и синтетические данные с обозначенными условиями. Их нельзя объявлять независимой квалификацией людей.
